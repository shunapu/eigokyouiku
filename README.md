# Phonics Adventure MVP

小さな子ども向けのフォニックス英語学習アプリの MVP です。

## 使い方

1. このフォルダでローカルサーバーを起動します
   - `python3 -m http.server 8000`
2. ブラウザで `http://localhost:8000` を開きます
3. 文字の音と単語を聞き、風船ゲームでアルファベットを練習します

## ファイル構成

- `index.html`: アプリのレイアウト
- `style.css`: 見た目と幼児向けのデザイン
- `script.js`: レッスンデータとゲームロジック

## こんな機能を持っています

- 文字ごとのレッスン
- アルファベット表からA〜Zのレッスンを選択
- フォニックス音の音声再生（Web Speech API、日本語の音表記による近似）
- 例の単語表示
- 単語を選んで英語音声を再生
- アルファベット風船・泡ゲーム（開始時にランダム選択、10点満点、達成時に花吹雪・クラッカーでお祝い）
- ゲームの得点表示
